# CASMI 2026 – Molecular Structure Prediction

This project explores molecular structure identification from tandem mass spectrometry (MS/MS) data using Python.

## Project Overview
The notebook processes mass spectra, searches for exact matches in reference spectra, and generates ranked molecular structure candidates using SMILES representations.

## Tools and Technologies
- Python
- Pandas and NumPy
- PyArrow
- Kaggle Notebooks

## Competition
CASMI 2026 – Molecular Structure Identification from Mass Spectra

## Results
The initial Kaggle submission achieved a public score of 0.083.

`casmi-2026-submission.ipynb`
